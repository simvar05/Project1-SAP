# Project1-SAP

Обща информация за приложението 
Система за управление на версии на документи представлява уеб базирано приложение, предназначено за създаване, редактиране, проследяване и одобряване на различни версии на документи в екипна среда.
Приложението е подходящо при:
•	работа по договори и официални документи
•	студентски и екипни проекти
•	софтуерна документация
•	вътрешни фирмени процедури
•	всякакъв тип колаборация върху текстови файлове
Основни характеристики:
•	Създаване на документи
•	Версиониране на всяка промяна
•	История на версиите
•	Одобрение и отказ от ревюиращи
•	Коментари към версии
•	Роли и контрол на достъпа
•	Централизирано съхранение
Системата е разделена на 3 слоя:
Представителен (Frontend),Backend и Информационен. Frontend комуникира с backend чрез REST API. Информацията се съхранява в база данни на MySQL.

Основни понятия
Документ - Основната единица в системата.
Версия на документ - Всяка промяна създава нова версия.
Потребител - Лице, което използва системата. 4 вида – администратор, автор, ревюиращ, читател.
Коментар - Забележка към конкретна версия.

Стартиране на приложението:
1.	Стартира се MySQL сървър.
2.	Стартира се Spring Boot приложението.
3.	Създава се база данни автоматично.
4.	Приложението се достъпва на: http://localhost:8080
5.	Създава се/Влиза се в акаунт.

Регистрация и вход в приложението – администратор, потребител
Потребител може да бъде създаден при първоначална инициализация.
При регистрация се задават: име, парола, роля.
След успешен вход потребителят получава достъп до функционалности според ролята си.
При повторно влизане се вкарват само име и парола.

Функции на администратор:

•	Преглед на всички потребители

•	Контрол върху процеса на одобрение

•	Проследяване на всички версии

•	Достъп до история на промените

•	Поддръжка на системата

•	Управление на базата данни

•	Наблюдение на активността

Функции на потребител:
-Автор:

•	Създаване на нови документи

•	Редактиране на документи

•	Създаване на нови версии

•	Преглеждане на историята на версиите
-Ревюиращ:

•	Преглеждане на версии

•	Одобряване на версии

•	Отхвърляне на версии

•	Добавяне на коментари
-Читател:

•	Виждане на одобрени версии

•	Разглеждане на документи
